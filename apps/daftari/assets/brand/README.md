# Daftari (دفتری) — Brand Asset Package

## What's here

- **brand-guidelines.pdf / .png** — one-page visual spec sheet: colors, type, logo lockups, clear space, don'ts.
- **svg-sources/** — every logo file as clean, editable vector SVG (fonts converted to outlines, so they'll open correctly in Illustrator/Figma/Inkscape even without the brand fonts installed):
  - `primary-logo-horizontal.svg` — the recommended primary logo (icon + دفتری + Daftari), light background
  - `primary-logo-horizontal-dark.svg` — same, for dark backgrounds
  - `wordmark-arabic-only.svg` — دفتری alone, with the receipt-roll accent on the ت
  - `wordmark-with-tagline.svg` — دفتری + "DAFTARI" tagline, no icon
  - `app-icon.svg` / `maskable-icon.svg` — the standalone mark
  - `alt-icon-direction-a.svg`, `alt-icon-direction-b.svg`, `alt-lockup-direction-b.svg` — the two alternate concept directions (see concept-comparison.png), kept in case you'd rather go a different way
- **icons/** — app-icon-512.png, app-icon-1024.png, maskable-icon-512.png, primary-logo-2000w.png
- **favicons/** — 16/32/48/64/128/256 PNG + a combined favicon.ico
- **social/** — Twitter header (1500×500), LinkedIn cover (1584×396), avatar (400×400, safe-cropped for circular display), as both SVG and PNG
- **concept-comparison.png** — the three original brief directions side by side, for reference

## The recommended direction

**Direction C's icon** (the geometric د mark) is paired with **Direction A's wordmark** (the Reem Kufi دفتری with the receipt-roll ت) as the primary logo — they share the same letterform, so they read as one coherent system rather than two competing ideas. Direction B (notebook/ledger icon) is included in full as a genuine alternative if you prefer a more literal "ledger" metaphor over the abstract letterform.

## Notes on the receipt-roll detail

The dot on ت is replaced with a small stylized paper-roll shape in gold — a literal nod to "receipt roll" per the brief, sized and positioned to sit where the dot naturally falls.

## Fonts used (for future editing)

- **Reem Kufi** — Arabic display/logotype (the دفتری wordmark)
- **Cairo** — bilingual UI/body font (Latin + Arabic), used for "Daftari" and any interface text
- Both are open-source (SIL OFL) and free to use commercially.
